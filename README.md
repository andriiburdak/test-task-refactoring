# TesterResults

Консольний застосунок на .NET 8 для читання та аналізу лог-файлів тестерів друкованих плат (PCB), підрахунку статистики (Total, Pass, Fail, Pass on Retest, Avg Cycle Time) та формування звітів у консоль і CSV.

---

## Запуск застосунку

### 1. Стандартний запуск (за замовчуванням)
За замовчуванням застосунок зчитує `.log` файли з папки `data/` у корені проєкту та зберігає підсумковий звіт у `reports/results.csv`:

```bash
dotnet run --project src/TesterResults
```
### 2. Запуск із кастомними аргументами CLI

Ви можете передати шлях до папки з логами (1-й аргумент) та шлях до вихідного CSV-файлу звіту (2-й аргумент):
```bash

dotnet run --project src/TesterResults -- "data" "reports/results.csv"
```
### Формат вихідного CSV-звіту

Згенерований файл містить наступні колонки:

    tester — ідентифікатор тестера;

    всього — загальна кількість оброблених валідних записів;

    pass — кількість успішно пройдених тестів;

    fail — кількість тестів із помилкою;

    pass on retest — кількість плат, які пройшли тест після попереднього FAIL;

    середній час циклу — середній час тестування (секунди, округлені до 2 знаків).
